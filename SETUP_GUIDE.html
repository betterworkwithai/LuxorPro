Part 1 of 4

WhatsApp Bot

You'll create a Meta (Facebook) business account, get a WhatsApp phone number, connect it to your Supabase backend, and configure your API keys. Once done, users can send messages like "gastei 50 no mercado" and the bot registers the transaction automatically in Luxor Pro.

1

Create a Meta Developer Account

  1. Go to developers.facebook.com
  2. Click Get Started (top right)
  3. Log in with any Facebook / Meta account
  4. Accept the developer terms
  5. You are now a Meta developer ✓
2

Create a Meta App

  1. On the developer dashboard click My Apps → Create App
  2. Choose Business as the app type → click Next
  3. Fill in: App name Luxor Pro Bot and your contact email
  4. Click Create App
  5. On the next screen (Add Products) find WhatsApp and click Set up
3

Get your WhatsApp credentials

After clicking Set up you land on WhatsApp → Getting Started.

  1. Under Step 1 — Select phone numbers, Meta gives you a free test number — click it to select it
  2. Copy and save these two values (you will need them in Step 8):
ValueWhere to find itExample
Phone Number IDShown below "From" on Getting Started123456789012345
Temporary Access TokenClick Generate buttonEAABs...
The temporary token expires in 24 hours. You will replace it with a permanent one in Step 4.
4

Create a permanent System User token

  1. Go to business.facebook.com
  2. Click the gear icon ⚙️ → Business Settings
  3. Left sidebar: Users → System Users
  4. Click Add → name it luxorpro-bot → role: Admin → click Create System User
  5. Click Generate New Token
  6. Check these two permissions: whatsapp_business_messaging and whatsapp_business_management
  7. Click Generate Token and copy it — this is your permanent WHATSAPP_TOKEN
Save this token in a password manager. You cannot view it again after closing the dialog.
5

Register a real WhatsApp number (optional — skip for testing)

The free Meta test number only sends to approved numbers. For production, add your own:

  1. In Meta Developer Console → WhatsApp → Phone Numbers → Add phone number
  2. Enter a phone number you own (can be a virtual number)
  3. Verify via SMS or call as prompted
  4. Copy the new Phone Number ID and save it
Virtual numbers from services like Twilio, VoIP.ms, or a dedicated Brazilian SIM card all work.
6

Set up the Webhook

  1. In Meta Developer Console → WhatsApp → Configuration
  2. Under Webhook, click Edit
  3. Fill in Callback URL:
https://YOUR-PROJECT-REF.supabase.co/functions/v1/whatsapp-webhook
# Find YOUR-PROJECT-REF at supabase.com/dashboard → your project → Settings → API
  1. Fill in Verify token: make up any secret word, e.g. luxor_webhook_2026
  2. Click Verify and save
  3. Under Webhook fields click Manage and toggle ON: messages
  4. Click Done
7

Get your Anthropic (Claude) API key

  1. Go to console.anthropic.com
  2. Sign up or log in
  3. Click API Keys → Create Key
  4. Name it luxorpro-whatsapp-bot
  5. Copy the key (starts with sk-ant-...) — you won't see it again
8

Set Supabase secrets

Open a terminal in your project folder and run each command (paste your real values):

# 1. Install Supabase CLI (run once, skip if already installed)
npm install -g supabase

# 2. Log in to Supabase
supabase login

# 3. Link to your project (find project-ref at supabase.com → Settings → General)
supabase link --project-ref YOUR_PROJECT_REF

# 4. Set secrets one by one
supabase secrets set WHATSAPP_TOKEN="your_permanent_token_here"
supabase secrets set WHATSAPP_PHONE_NUMBER_ID="your_phone_number_id_here"
supabase secrets set WHATSAPP_VERIFY_TOKEN="luxor_webhook_2026"
supabase secrets set ANTHROPIC_API_KEY="sk-ant-your_key_here"
SUPABASE_SERVICE_ROLE_KEY is automatically injected by the Supabase runtime — you do not need to set it manually.
9

Deploy the database migration and Edge Functions

# Creates the whatsapp_links and whatsapp_sessions tables
supabase db push

# Deploys the webhook handler and phone-linking function
supabase functions deploy whatsapp-webhook
supabase functions deploy whatsapp-verify
10

Test it end-to-end

  1. In Meta Developer Console → WhatsApp → Getting Started
  2. Under Step 2, enter your personal WhatsApp number and click Send message — you should receive a template message
  3. Open Luxor Pro → Settings → WhatsApp Bot
  4. Enter your phone number and click Send Code
  5. You receive a 6-digit code on WhatsApp
  6. Enter the code and click Verify
  7. Send a message to your bot number: "gastei 50 no mercado"
  8. Bot replies asking you to confirm → reply "sim" → transaction appears in your Luxor Pro dashboard ✓
Try all commands: /extrato, /saldo, /metas, /ajuda — each should return a formatted reply.

Android App — Google Play Store

You'll build the web app, wrap it with Capacitor (no React Native rewrite needed), open it in Android Studio, sign it, and upload it to the Google Play Console. Budget about 2–3 hours the first time.

1

Install prerequisites

ToolWhere to get itNotes
Node.jsnodejs.org (LTS version)Required to run the build
Android Studiodeveloper.android.com/studioAccept all defaults during install
Android SDK 34Inside Android Studio: Tools → SDK ManagerInstall after opening Android Studio
Java (JDK 17) is installed automatically with Android Studio. No separate download needed.
2

Install project dependencies

cd "C:\Users\gabia\OneDrive\Desktop\AI\luxorpro"
npm install

This installs Capacitor and all other packages. Takes 1–3 minutes.

3

Initialize Capacitor for Android

npx cap add android

This creates the android/ folder in your project. Run only once.

4

Build and sync

npm run cap:sync

This builds the web app and copies everything into the Android project. Run this every time you make changes to the app.

5

Open in Android Studio

npx cap open android

Android Studio opens. Wait for it to finish syncing (progress bar at the bottom — may take 2–5 minutes the first time).

6

Create a keystore — app signing (do this once)

The keystore is your app's digital identity. If you lose it, you can never update the app on Google Play. Back it up somewhere safe immediately.
  1. In Android Studio: Build → Generate Signed Bundle / APK
  2. Choose Android App Bundle → click Next
  3. Click Create new under "Key store path"
  4. Save it somewhere safe, e.g. C:\Users\gabia\luxorpro-keystore.jks
  5. Fill in all fields:
FieldWhat to enter
PasswordA strong password — save it in your password manager
Key aliasluxorpro
Key passwordSame or different strong password — save it
Validity25 years
First and Last NameYour name
Country CodeBR
  1. Click OK → Next → choose Release → click Finish
  2. Android Studio builds a .aab file — find it in android/app/release/
7

Create a Google Play Developer account

  1. Go to play.google.com/console
  2. Sign in with a Google account
  3. Pay the one-time $25 registration fee (credit card)
  4. Fill in your developer profile (name, email, phone)
  5. Accept the Developer Distribution Agreement
8

Create the app on Google Play

  1. In Play Console: All apps → Create app
  2. App name: Luxor Pro
  3. Default language: Portuguese (Brazil)
  4. App or game: App
  5. Click Create app
9

Fill in the store listing

Left sidebar: Grow → Store presence → Main store listing

FieldRequirement
Short descriptionMax 80 characters
Full descriptionMax 4000 characters — describe all features
App iconUpload public/icon-512.png (512×512 px)
ScreenshotsAt least 2, taken from Android emulator (phone size)
Feature graphic1024×500 px banner — create in Canva (free)
Privacy policyRequired — create a free one at privacypolicygenerator.info
10

Upload your build and publish

  1. Left sidebar: Release → Production → Create new release
  2. Click Upload and select your .aab file from Step 6
  3. Write release notes (what's new)
  4. Click Save → Review release → Start rollout to Production
  5. Google reviews the app — usually 1–3 days for first submission
After the first approval, updates are usually reviewed within hours.

iOS App — Apple App Store

The process mirrors Android but uses Xcode on a Mac. You need a physical or virtual Mac — iOS builds cannot be produced on Windows.

1

Prerequisites (on Mac)

A Mac computer is required. If you don't have one, consider renting a Mac cloud machine at MacStadium.com or using a GitHub Actions macOS runner.
ToolWhere to get it
XcodeMac App Store → search "Xcode" → Install (~15 GB, be patient)
Xcode CLI toolsOpen Mac Terminal → xcode-select --install
Node.jsnodejs.org (LTS)
CocoaPodsTerminal → sudo gem install cocoapods
2

Copy the project to your Mac

Copy the project folder to the Mac (USB drive, cloud drive, or zip). Then in Terminal:

cd /path/to/luxorpro
npm install
3

Add iOS and sync

npx cap add ios         # run once — creates ios/ folder
npm run cap:sync         # run every time you change the app
4

Open in Xcode

npx cap open ios

Xcode opens. Let it index and resolve dependencies (progress shown at top).

5

Join Apple Developer Program

  1. Go to developer.apple.com/programs
  2. Click Enroll
  3. Sign in with an Apple ID (create one if needed at appleid.apple.com)
  4. Choose Individual enrollment
  5. Pay $99/year (credit card or PayPal)
  6. Approval is usually instant for individuals — check your email
6

Configure the app in Xcode

  1. In the left panel, click on App (the top-level blue icon)
  2. In the main panel, click Signing & Capabilities
  3. Check Automatically manage signing
  4. Under Team: click the dropdown → Add an account → sign in with your Apple Developer Apple ID
  5. Set Bundle Identifier to: com.luxorpro.app
  6. Click General tab and set:
    • Display Name: Luxor Pro
    • Version: 1.0.0
    • Build: 1
7

Add app icons

  1. In Xcode, click Assets.xcassets → AppIcon
  2. Drag public/icon-512.png from your project into the 1024×1024 slot
  3. Xcode auto-generates all required sizes
8

Create the App Store listing

  1. Go to appstoreconnect.apple.com
  2. Click Apps → + (New App)
  3. Fill in:
FieldValue
NameLuxor Pro
Primary LanguagePortuguese (Brazil)
Bundle IDcom.luxorpro.app
SKUluxorpro-v1
If "com.luxorpro.app" doesn't appear in the Bundle ID dropdown, first register it at developer.apple.com → Certificates, IDs & Profiles → Identifiers → + → App IDs.
  1. Fill in the description, keywords, support URL, and screenshots
9

Archive and upload from Xcode

  1. In Xcode top bar, set the destination to Any iOS Device (arm64)
  2. Menu: Product → Archive (takes 3–10 minutes)
  3. The Organizer window opens automatically
  4. Click Distribute App → App Store Connect → Next → Next → Upload
  5. Wait for upload to complete
  6. In App Store Connect, go to TestFlight — your build appears after ~10 min processing
  7. When processed: App Store → + Version → 1.0.0, attach the build → Submit for Review
  8. Apple reviews in 1–3 days
After the first approval, updates usually review in under 24 hours.

Electron Desktop App

Electron packages the existing web app as a native desktop binary. You get a .exe installer for Windows and a .dmg for macOS. No app store account required — you can distribute the installer directly.

1

Install dependencies

cd "C:\Users\gabia\OneDrive\Desktop\AI\luxorpro"
npm install

Installs Electron (~150 MB), electron-builder, and helpers. Takes 2–5 minutes.

2

Test in development mode

npm run electron:dev

This starts the Vite dev server and simultaneously opens Luxor Pro in an Electron window. You should see the app running as a native desktop window. Close it when done testing.

3

Build the installer

npm run electron:build

This will take 3–10 minutes. When done, find your installer in dist-electron/:

PlatformOutput fileHow to distribute
WindowsLuxor Pro Setup 1.0.0.exeShare the .exe directly or upload to a file host
macOSLuxor Pro-1.0.0.dmgShare the .dmg or upload to GitHub Releases
LinuxLuxor Pro-1.0.0.AppImageShare the AppImage
4

Set up auto-updates (optional but recommended)

Auto-updates let existing users get new versions automatically.

  1. Create a GitHub account at github.com
  2. Create a new repository named luxorpro-desktop
  3. Open electron-builder.yml and update the owner field to your GitHub username
  4. Create a GitHub Personal Access Token:
    • GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
    • Click Generate new token (classic)
    • Check the repo scope → Generate → copy the token
  5. Build and publish in one command:
# Windows
set GH_TOKEN=your_github_token_here
npm run electron:build -- --publish always

# macOS / Linux
export GH_TOKEN=your_github_token_here
npm run electron:build -- --publish always

The installer is automatically uploaded to GitHub Releases. Users with the app already installed will see an update notification next time they open it.

5

Code signing (removes security warnings — optional)

Without signing, Windows shows a SmartScreen warning and macOS shows "unidentified developer." You can dismiss these, but for a professional release, sign the app.

PlatformWhat you needApproximate cost
WindowsCode Signing Certificate from DigiCert or Sectigo~$200/year
macOSApple Developer account (Part 3) + Developer ID certificate (free with membership)Included in $99/year

For macOS, once your Apple Developer account is set up and Xcode is configured, electron-builder picks up the certificate automatically when you run the build on a Mac.

For Windows, add these lines to electron-builder.yml:

win:
  certificateFile: path/to/your-cert.pfx
  certificatePassword: your_cert_password

Troubleshooting

ProblemSolution
WhatsApp bot doesn't respond Check logs: Supabase Dashboard → Edge Functions → whatsapp-webhook → Logs
Webhook verification fails in Meta Make sure WHATSAPP_VERIFY_TOKEN in Supabase secrets exactly matches what you typed in Meta Console
Bot says "número não vinculado" Open Luxor Pro → Settings → WhatsApp Bot and link your number first
Android build fails with SDK error Android Studio → Tools → SDK Manager → install Android SDK 34
npx cap sync fails Run npm run build first — the dist/ folder must exist before syncing
iOS build says "no team" Xcode → Signing & Capabilities → add your Apple Developer account via "Add an account"
iOS "Bundle ID already exists" Register com.luxorpro.app at developer.apple.com → Identifiers → + → App IDs
Electron app shows blank screen Run npm run electron:dev and press Ctrl+Shift+I to open DevTools and see errors
Electron build says "electron not found" Run npm install first to install all dependencies
macOS "cannot be opened" warning Right-click the app → Open → Open anyway. Or distribute via Mac App Store with code signing.
Windows SmartScreen warning Click "More info" → "Run anyway". Disappears after enough users have installed the app or after code signing.
